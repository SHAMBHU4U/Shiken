---
name: Home dashboard visual roles
description: Color and contrast rules for the SHIKEN home dashboard and goal selector.
---

The home dashboard keeps white cards and the off-white canvas restrained, using the active goal accent for the selection badge and goal panels. The SHIKEN wordmark, Hindi tagline, motivation quote, and My Progress label should use dark, high-contrast text.

**Why:** The reference design was visually calm, but low-contrast quote and progress copy reduced readability. Goal-specific accents add scanability without making the dashboard brighter.

**How to apply:** Preserve the existing white/slate surfaces and apply accents through borders, icon wrappers, badges, and subtle tints. Do not replace the dashboard with bright gradients or dark surfaces unless explicitly requested.
