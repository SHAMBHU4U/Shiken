---
name: Quiz interface color roles
description: Semantic color assignments for the student test-taking screen.
---

The quiz interface uses a softer slate canvas with dark navy text and reserves bright color for actions: blue for the clock, amber for saved/bookmarked questions, cyan for language translation, orange for Skip, violet for the question palette, and emerald for selected answers.

**Why:** The test screen contains several compact controls that students need to distinguish quickly; one shared accent made the actions harder to scan and white surfaces were visually tiring.

**How to apply:** Preserve these semantic roles when adding or restyling quiz actions. Keep neutral cards and options in slate tones, and use high-contrast dark text rather than white/translucent text on light surfaces.
